## 📌 Project Overview

This repository contains the practical work and learning activities completed as part of **Task 1** under the NSDA Android Mobile Application Development (Level 4) program.

The primary objective is to develop foundational knowledge of Kotlin programming and prepare the development environment for native Android application development.

## 🎯 Learning Objectives

- Understand the fundamentals of Kotlin.
- Learn basic programming syntax.
- Understand variables and data types.
- Perform arithmetic operations.
- Work with operators and expressions.
- Develop problem-solving skills using Kotlin.

## 🛠️ Technologies & Tools

- **Programming Language:** Kotlin
- **IDE:** Android Studio
- **JDK:** Java Development Kit
- **Platform:** Android
- **Version Control:** Git & GitHub

## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project in Android Studio or IntelliJ IDEA.

3. Configure the Kotlin development environment.

4. Open the `Main.kt` file.

5. Run the program.

## 💻 Sample Kotlin Code

```kotlin
fun main() {
```
